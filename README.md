# YourCook

YourCook is a recipe and cooking guidance platform that helps users prepare
different types of dishes through step-by-step instructions.

## Features

- Indian Recipes
- Chinese Recipes
- American Recipes
- Step-by-Step Cooking Guides
- Beginner Friendly

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
